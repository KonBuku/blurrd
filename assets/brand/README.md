# blurrd brand assets

The blurrd logo is a name-tag pill whose left part is crisp and whose right
part melts into a gaussian blur: what blurrd does to a player name. The icon
is monochrome (white mark on a near-black tile); colour belongs to the user
interface, never to the logo.

Every file in this folder is generated by [`src/brand.py`](src/brand.py).
Do not edit the SVG or PNG files by hand; change the generator and run it
again.

## Files

| File                                                      | Use                                                                                               |
| --------------------------------------------------------- | ------------------------------------------------------------------------------------------------- |
| `blurrd-icon.svg`                                         | Master app icon on the macOS grid (tile 824/1024, 100 unit transparent margin).                   |
| `blurrd-icon-fullbleed.svg`                               | Windows/Linux master (tile 960/1024), so the icon does not look small in the taskbar or Explorer. |
| `blurrd-icon-small.svg`                                   | Simplified mark for 32 px and below: no blur filter, the pill fades by opacity instead.           |
| `blurrd-icon-light.svg`                                   | White tile with an ink mark, only for dark marketing surfaces.                                    |
| `blurrd-glyph.svg`                                        | Mark without a tile. Uses `currentColor`, so the UI can colour it (title bar, empty states).      |
| `blurrd-glyph-ink.svg`, `blurrd-glyph-white.svg`          | Mark without a tile in fixed colours.                                                             |
| `blurrd-lockup-on-light.svg`, `blurrd-lockup-on-dark.svg` | Icon plus wordmark, for light and dark backgrounds.                                               |
| `blurrd-wordmark-ink.svg`, `blurrd-wordmark-white.svg`    | Wordmark only.                                                                                    |
| `social-preview.svg`, `social-preview.png`                | GitHub social preview, 1280 x 640.                                                                |
| `app-icon.png`                                            | 1024 px render of the full-bleed icon; the source for `tauri icon`.                               |
| `app-icon-macos.png`                                      | 1024 px render of the macOS-grid icon.                                                            |
| `png/`                                                    | 1024 px wide renders of the light icon and the lockups.                                           |
| `tauri/`                                                  | Hand-tuned icons that replace the `tauri icon` output (see below).                                |

## App icons

`tauri icon` only downsamples its source, which turns the blur into grey
mush at 16, 24 and 32 px. Generate the standard set first and then replace
three files with the hand-tuned ones from `tauri/`:

1. `pnpm tauri icon assets/brand/app-icon.png`
2. Copy `tauri/icon.ico` (layers 32, 16, 24, 48, 64 and 256 px, the 32 px
   layer first; 16 to 32 px come from the small variant) and
   `tauri/32x32.png` into `apps/desktop/src-tauri/icons/`.
3. Copy `tauri/icon.icns` (built from the macOS-grid master) over the
   generated one.

## Usage rules

- Keep clear space of at least a quarter of the tile height around the icon.
  Below 24 px of height, use the small icon instead of the lockup.
- Never recolour the tile or the mark, never set the wordmark in capitals and
  never add effects such as shadows, glows or outlines.
- The README header uses the lockup pair with `<picture>` and
  `prefers-color-scheme`.
- The GitHub social preview has to be uploaded by hand under
  Settings > General > Social preview.

## Regenerating the assets

The generator needs Python 3.12 or newer with the packages in
[`src/requirements.txt`](src/requirements.txt), and Node.js with two npm
packages installed into any scratch folder outside the repository:

```sh
npm install --prefix <scratch> @resvg/resvg-js@2.6.2 geist@1.7.2
python -m pip install -r assets/brand/src/requirements.txt
python assets/brand/src/brand.py --deps <scratch> --sheet
```

`--sheet` also writes `final-sheet.png` (ignored by git) with the icon at
256/128/32 px and the small variant at 32/24/16 px; check it after every
change. The output is deterministic, so an unchanged generator produces no
diff.
