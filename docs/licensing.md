## Source code

All code in this repository, including the desktop user interface in
`apps/desktop/src` (design tokens, styles, components and icons), is
written for blurrd and licensed under GPL-3.0-only. New source files need no
per-file licence header; the repository licence applies.

The user interface is built on these libraries, which are installed from
npm and not copied into the repository:

| Library                 | Licence    | Use                                       |
| ----------------------- | ---------- | ----------------------------------------- |
| React, React DOM        | MIT        | rendering                                 |
| Tailwind CSS            | MIT        | utility classes generated from the tokens |
| clsx, tailwind-merge    | MIT        | class name composition (`cn`)             |
| Lucide (`lucide-react`) | ISC        | generic action icons                      |
| Tauri (`@tauri-apps/*`) | Apache-2.0 | desktop shell and IPC                     |

Libraries added later are listed here in the commit that adds them. The
licence texts of everything the installer ships are collected in
`THIRD-PARTY-NOTICES.md`, generated before each release from the Rust and
npm dependency trees.

## Fonts and images

The app bundles no UI font: it uses the operating system's interface font
(Segoe UI Variable on Windows 11) and `Cascadia Mono` or the system
monospace font. The brand assets in `assets/brand` are generated by
`assets/brand/src/brand.py`; the wordmark outlines come from Geist
(OFL-1.1), and no font file is committed. The synthetic test fixtures use
OFL-1.1 fonts that are downloaded at test time (`tests/fonts/fonts.toml`).

## Shipped binaries

- **FFmpeg** (LGPL-2.1-or-later): blurrd ships its own minimal build
  without GPL components, linked dynamically, so users can replace the
  DLLs. The build recipe and the matching source archive are published
  next to the binaries.
- **ONNX Runtime** (MIT) is shipped with its `ThirdPartyNotices.txt`;
  **DirectML** under the Microsoft redistributable licence.
- **OCR models and dictionary** (PP-OCR, Apache-2.0) are bundled with a
  record of how they were converted.

## Trademarks

Neither the blurrd name, its logo nor its user interface uses the names,
logos, fonts or other assets of game publishers or other products. The
README and the About dialog carry the required trademark statements.
