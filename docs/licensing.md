## What the licence means

This summary is not legal advice; [`LICENSE`](../LICENSE) and
[`NOTICE`](../NOTICE) are what count.

- **Use:** everyone may use blurrd for any purpose, also commercially,
  for example to blur the names in videos you publish or are paid for.
  The GPL places no conditions on running the program or on the videos
  it produces.
- **Share and change:** you may copy, modify and redistribute blurrd.
  Whoever distributes it, changed or unchanged, must do so under
  GPL-3.0-only with the same additional terms and must make the complete
  corresponding source code available to the recipients.
- **Credit (additional term 1, section 7(b)):** every copy and modified
  version must keep the attribution

  ```text
  blurrd by KonBuku (https://github.com/KonBuku/blurrd)
  ```

  in the app's About or credits screen and in its documentation. The app
  shows it under About, together with the copyright line
  "Copyright 2026 Konrad (KonBuku)".

- **Modified versions (additional term 2, section 7(c)):** must be marked
  as changed and must not be presented as the original blurrd.
- **Linking permission (additional term 3):** blurrd may be linked and
  distributed with ONNX Runtime with DirectML (`DirectML.dll`), the
  NVIDIA driver interfaces for NVDEC and NVENC and Windows system
  components, whose licences are not GPL-compatible.

## Commercial licence

Companies that want to use blurrd's code in a closed-source product, or
distribute blurrd without the obligations of the GPL, can get a separate
commercial licence from the author. Ask through a
[GitHub issue](https://github.com/KonBuku/blurrd/issues) or the author's
[GitHub profile](https://github.com/KonBuku). This is possible because
contributors agree that their contributions may also be licensed that
way (see [CONTRIBUTING.md](../CONTRIBUTING.md#licensing)).

## Source code

All code in this repository, including the desktop user interface in
`apps/desktop/src` (design tokens, styles, components and icons), the
brand assets, the documentation and its images, is written for blurrd
and licensed under GPL-3.0-only with the additional terms in `NOTICE`.
The Rust crates and npm packages declare it with the SPDX identifier
`GPL-3.0-only`; they are not published to crates.io or npm. New source
files need no per-file licence header; the repository licence applies.

The licence checks (`cargo deny`, `about.toml`) skip blurrd's own private
crates and allow only permissive licences for dependencies. Every allowed
licence (Apache-2.0, MIT, BSD, ISC, Zlib, MPL-2.0 and the others in
`deny.toml`) is compatible with GPL-3.0, and keeping the dependencies
permissive also keeps the commercial licence possible.

## Fonts and images

The app bundles no UI font: it uses the operating system's interface font
(Segoe UI Variable on Windows 11) and `Cascadia Mono` or the system
monospace font. The brand assets in `assets/brand` are generated by
`assets/brand/src/brand.py`; the wordmark outlines come from Geist
(OFL-1.1), and no font file is committed. The synthetic test fixtures use
OFL-1.1 fonts that are downloaded at test time (`tests/fonts/fonts.toml`).

## Shipped binaries

The GPL covers only blurrd's own code. The components below keep their
own licences, which are unchanged and apply to them as they are; nothing
in blurrd's licence limits the rights they give, for example to replace
the LGPL FFmpeg DLLs. FFmpeg (LGPL-2.1-or-later, dynamically linked),
ONNX Runtime (MIT) and the models (Apache-2.0) are GPL-3.0-compatible;
DirectML, which is not, is covered by the linking permission in
`NOTICE`.

- **FFmpeg** (LGPL-2.1-or-later): blurrd ships its own minimal build
  without GPL components, linked dynamically, so users can replace the
  DLLs. The build recipe and the matching source archive are published
  next to the binaries.
- **ONNX Runtime** (MIT) is shipped with its `ThirdPartyNotices.txt`;
  **DirectML** under the Microsoft redistributable licence.
- **OCR models and dictionary** (PP-OCR, Apache-2.0) are bundled with a
  record of how they were converted.
